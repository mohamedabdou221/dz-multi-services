# Assets - Fichiers de production

Ce dossier contient les fichiers de production qui ne sont pas directement inclus dans le site public.

## Structure

- `cahier-des-charges/` - Cahier des charges v2.2 (Word)
- `charte-graphique/` - Charte graphique complète (12 pages)
- `photos-prestations/` - Photos réelles des prestations (mariages, imprimerie, tournages)
- `maquettes/` - Maquettes de design (accueil, formulaire de mariage, fiche demande, devis)

## Instructions

### Cahier des charges
Placer le fichier Word v2.2 dans `cahier-des-charges/`.

### Charte graphique
Copier le dossier complet de la charte graphique dans `charte-graphique/`.

### Photos de prestations
Ajouter les photos réelles des prestations dans `photos-prestations/`. Les photos doivent être :
- De haute qualité
- Bien cadrées
- Avec des ratios constants
- Nommées de manière descriptive (ex: mariage-dupont-2024-01.jpg)

### Maquettes
Les maquettes design doivent être placées dans `maquettes/`. Formats acceptés : Figma, Sketch, PNG, PDF.
